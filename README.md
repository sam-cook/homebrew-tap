# sam-cook/homebrew-tap

Homebrew casks for apps by [@sam-cook](https://github.com/sam-cook).

```sh
brew install --cask sam-cook/tap/review-queue
```

| Cask | App |
| --- | --- |
| `review-queue` | [Review Queue](https://github.com/sam-cook/review-queue): a macOS menu bar app for the GitHub pull requests that need your review |

Casks here are updated automatically by each app's release workflow. To change one, edit the
template in the app's repository (for example `packaging/homebrew/review-queue.rb`).
